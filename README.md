# isaaclua: Lua-моды для Айзека на Switch

Плагин для **The Binding of Isaac: Repentance на Switch** (1.7.9b, 010021C000B6A000), который встраивает
в игру Lua 5.3 (та же версия, что на ПК) и запускает моды в формате ПК: `mods/<имя>/main.lua`,
`RegisterMod`, `mod:AddCallback(ModCallbacks...)`, `Isaac.*`, `EntityPlayer`, `Vector`. Файлы модов не
меняются: всё, что нужно моду, дописывается в загрузчик.

Статус (0.99.162): **загрузчик готов**. На Switch вызываются все колбэки ПК-версии, из 1498 имён API
ПК (IsaacDocs) есть 1474; чего нет, перечислено в `coverage/api_coverage.md`. Моды грузят свои
`resources/` и `content/` (предметы, сущности, пулы, музыка, звуки), сохраняют настройки, работает
Mod Config Menu, экранная клавиатура и консоль. Поддержка Repentance+ встроена в загрузчик, а сам мод `isaac-repplus`
с данными REP+ сюда не входит и ещё доделывается (`docs/README-REPPLUS.md`).

Не каждый ПК-мод заработает: Switch-версия игры урезана (нет шейдеров, экран 426x240 вместо 480x270,
меньше памяти), а большие моды (Fiend Folio, Epiphany) медленнее, чем на ПК. Что проверено на консоли,
есть в таблицах ниже.

## Что скачать

Архив `isaaclua_v<версия>.zip` на странице [Releases](https://github.com/mrcucumber790/isaaclua/releases):
только загрузчик (`exefs/subsdk8`) и настройки (`romfs/isaaclua.ini`), модов в нём нет. Моды берутся с ПК
(папка `mods` игры или Steam Workshop) и кладутся как написано ниже.

Нашёл проблему: [открой issue](https://github.com/mrcucumber790/isaaclua/issues/new/choose) по форме,
там написано, какие файлы приложить.

## Как поставить (Switch с Atmosphere)

1. Скопировать папку `atmosphere/` из архива в корень SD-карты (с заменой файлов).
2. Положить моды (см. ниже) и запустить игру. В забеге вверху экрана на пару секунд появится `isaaclua v<версия> (Lua 5.3.6), N mod(s) loaded`.

Моды кладутся так же, как на ПК, только в romfs игры:
`sd:/atmosphere/contents/010021C000B6A000/romfs/mods/<папка мода>/main.lua`. Выключить мод: пустой файл
`disable.it` в его папке или экран «Моды» в главном меню. Если игра вылетела, Atmosphere пишет отчёт в
`sd:/atmosphere/crash_reports/`: приложи самый новый к issue (форма подскажет, что ещё нужно).

## Сохранения модов

`mod:SaveData(str)` пишет в сохранение самой игры (то же, где прогресс), в файл
`isaaclua/<имя мода>.dat`, и сразу фиксирует запись: настройки остаются после выхода. Игра открывает
своё сохранение, только когда выбран пользователь, то есть уже после загрузки модов; до этого данные
живут в памяти, а первое обращение после открытия читает файл. Сохранения модов удаляются вместе с
сохранением игры.

## Экранная клавиатура

ПК-моды читают клавиши (`Input.IsButtonTriggered(Keyboard.KEY_F1, 0)`), а у Switch клавиатуры нет.
В забеге **«+» и «−» вместе** открывают клавиатуру внизу экрана: стик или крестовина выбирают клавишу,
**A** нажимает её (держится, пока держишь A), **B** или ещё раз «+» и «−» закрывают. Shift, Ctrl и Alt
включаются и выключаются нажатием, как залипание клавиш. Пока клавиатура открыта, игра кнопок не видит.

Одиночное «+» (пауза) и «−» (карта) доходят до игры с задержкой в несколько кадров: так сочетание не
открывает паузу. В `isaaclua.ini` можно поменять сочетание (`keyboard = MINUS+R3`) и привязать кнопки
прямо к клавишам (`L3 = F1`); привязанную кнопку игра больше не видит.

Моды кладутся в `romfs/mods/<имя>/main.lua` (рядом можно `disable.it`, чтобы выключить, как на ПК).
Плагин назван `subsdk8`, чтобы стоять **вместе с isaacqol** (`subsdk9`), оба перехвата идут цепочкой.

Что должно быть видно: в забеге вверху по центру мелкий текст `isaaclua v0.84 (Lua 5.3.6), N mod(s) loaded`
(по нему видно, какая версия стоит). Ошибки модов и обращения к ещё не сделанным частям API тоже выводятся
вверху (красным и жёлтым).

## API

- Колбэки: все колбэки ПК-версии (`ModCallbacks`), с параметрами-фильтрами и возвращаемыми значениями
  как на ПК (порядок вызова сверен с дизассемблером ПК, `isaac-lua/re/callback_placement.md`).
- Классы: все классы IsaacDocs (`Entity*`, `GridEntity*`, `Room`, `Level`, `Game`, `ItemPool`, `ItemConfig`,
  `Sprite`, `Font`, `SFXManager`, `MusicManager`, `HUD`, `Input`, `Options`, `RNG`, `Vector`, `Color`...).
  Проверка на консоли (0.99.162): из 1498 имён нет 24, список и причины в `coverage/api_coverage.md`.
- Ресурсы модов: `resources/` (картинки, анимации, звуки, музыка, шрифты) и `content/` (`items.xml`,
  `entities2.xml`, `players.xml`, `itempools.xml`, `pocketitems.xml`, `music.xml`, `sounds.xml`,
  `costumes2.xml`, `challenges.xml`, `shaders.xml` для `MC_GET_SHADER_PARAMS`).
- Сохранения модов (`SaveData`/`LoadData`) в сохранении игры; порядок загрузки модов как на ПК (по
  имени из `metadata.xml`).
- Библиотеки: base, string, table, math, utf8, coroutine, debug, package, bit32, `os.time/clock/date`, `json`.

## Скорость

`perf = 1` в `isaaclua.ini` показывает внизу экрана обновления и кадры в секунду, время Lua на одно
обновление и три самых медленных мода. Замер 0.99.162 (комната с 8 врагами, моды Егора, 34 мода):
Lua 9-11 мс на обновление игры (обновлений 30 в секунду), 60 кадров в секунду. Больше всего берут
StageAPI с картой Minimap API (3-6 мс) и EID (около 1 мс). StageAPI нужен только модам на нём
(Fiend Folio и др.); без них его можно выключить. С 0.99.162 сборщик мусора Lua запускается реже: раньше
он работал почти непрерывно и давал рывки до 15-20 мс.

## Сборка

```
sh build.sh        # out/subsdk8; нужны clang, ld.lld, llvm-readelf, python3
sh test/run.sh     # тест на ПК с имитацией движка (gcc + ASan)
```

`build.sh` падает, если плагин импортирует что-то, чего нет в `tools/allowed_imports.txt` (это
импорты самой игры), или что-то экспортирует.

## Устройство

- `src/main.c`: перехват загрузки игры, проверка build id, запуск Lua, загрузка модов из `rom:/mods`,
  хуки движка (обновления и отрисовка сущностей, урон, предметы, комнаты, меню), экранный лог.
- `src/prelude.lua`, `src/api.lua`, `src/api_gen.lua`, `src/api_post.lua`: API ПК-версии поверх
  экспортированных функций игры и найденных смещений полей.
- `src/native.c`: `core.*` для Lua (вызов функций игры, чтение и запись памяти с проверкой адреса).
- `src/modfs.c`: ресурсы модов (`resources/`, `content/`). `src/keyboard.c`: экранная клавиатура.
- `src/repplus.lua`, `src/repplus_hooks.inc`: Repentance+ (мод `isaac-repplus`).
- `src/remote.c`, `src/remote.lua`: удалённый доступ, только в отладочной сборке.
- `lua/`: Lua 5.3.6 без изменений, кроме блока в конце `luaconf.h`.
